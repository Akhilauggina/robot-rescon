# RESCUE RECON — Project Presentation

Ready-to-present PowerPoint for the B.Tech mini-project defence.

## File

- **`Rescue-Recon-Presentation.pptx`** — 12 slides, defence-tech theme

## How to present

1. Open `Rescue-Recon-Presentation.pptx` in Microsoft PowerPoint or LibreOffice Impress.
2. Replace placeholders on slide 1:
   - `[College Name]`
   - `[Member 1], [Member 2], [Member 3]`
   - `[Guide Name]`
   - `[YYYY – YYYY]`
3. Present in slideshow mode (16:9).

## Rebuild (optional)

Screenshots live in `assets/`. To regenerate the PPTX after editing the script:

```bash
node ppt/build-pptx.mjs
```

Requires `pptxgenjs` (already listed in the project `devDependencies`).
